Kebijakan Privasi ELNUX

English version

Tanggal berlaku: 29 Oktober 2026

Pengembang: Tim pengembang ELNUX (Nusanian) Kontak: taobotapp@gmail.com

Dokumen ini menjelaskan data apa yang dikumpulkan, disimpan, dan dikirim oleh aplikasi ELNUX, serta data apa yang tidak pernah kami sentuh. ELNUX adalah dompet Lightning Network untuk Nusacoin (NUX) yang bersifat kustodi sendiri (self-custodial).

1. Apa itu dompet kustodi sendiri, dan kenapa itu penting untuk privasi Anda

Kustodi sendiri artinya kunci dompet Anda ada di tangan Anda, bukan di tangan kami.

  • Frasa backup 12 kata dan kunci dompet Anda dibuat dan disimpan hanya di perangkat Anda.
  • Kami tidak memiliki, tidak menyimpan salinan, dan tidak bisa memulihkan frasa atau kunci Anda. Kalau frasa hilang dan perangkat hilang atau rusak, dana tidak bisa dipulihkan oleh siapa pun, termasuk kami.
  • Kami tidak memegang dana Anda. Dana Anda ada di channel Lightning Anda dan, pada saat penutupan channel, di blockchain Nusacoin — bukan di rekening kami.

Karena itu, sebagian besar "data" dalam kebijakan ini sebenarnya tidak pernah sampai ke kami sama sekali: data itu hanya ada di perangkat Anda.

2. Data yang TIDAK kami kumpulkan

ELNUX tidak meminta Anda membuat akun, dan kami tidak mengumpulkan:

  • nama, alamat email, nomor telepon, atau alamat rumah Anda;
  • foto, kontak, lokasi, atau data perangkat lain yang tidak diperlukan;
  • kata sandi akun apa pun — ELNUX tidak punya kata sandi akun, karena tidak ada akun.

Kami juga tidak menggunakan pelacak iklan, tidak menjalankan analitik pihak ketiga, dan tidak menjual data apa pun kepada siapa pun, karena tidak ada data pribadi Anda yang kami miliki untuk dijual.

3. Data yang tersimpan hanya di perangkat Anda

Berikut ini disimpan secara lokal di perangkat Anda, di area penyimpanan pribadi aplikasi yang tidak bisa diakses aplikasi lain dalam kondisi normal:

  • Frasa backup dan seed dompet. Frasa 12 kata disimpan sebagai berkas terpisah, dan seed 64 byte yang diturunkan dari frasa itu disimpan sebagai berkas terpisah. Keduanya hanya ada di perangkat Anda dan tidak pernah dikirim ke server mana pun.
  • Data channel Lightning. Status channel, riwayat pembayaran, dan data node Lightning Anda disimpan di perangkat Anda.
  • Pengaturan aplikasi. Pilihan tema gelap/terang, pilihan bahasa, dan — bila Anda nanti memilihnya — profil LSP pilihan Anda. Pengaturan ini disimpan di perangkat Anda.
  • Saldo dan riwayat. Saldo dan riwayat pembayaran ditampilkan dari data node di perangkat Anda, bukan dari akun server.

Menghapus aplikasi umumnya menghapus data lokal ini dari perangkat Anda. Perhatian: menghapus aplikasi tanpa mencadangkan frasa berarti kehilangan akses ke dana Anda secara permanen (lihat bagian 7).

4. Data yang dikirim agar dompet bisa berfungsi

Agar bisa mengirim dan menerima pembayaran Lightning, dompet Anda harus terhubung ke dua jenis server. Ini adalah satu-satunya pengiriman data ke luar perangkat, dan hanya terjadi karena Anda memakai dompetnya:

a. Penyedia layanan Lightning (LSP)

Secara default, ELNUX terhubung ke LSP resmi Nusacoin. Jika di masa depan Anda memilih LSP lain dari daftar resmi atau memasukkan LSP sendiri, data ini akan terkirim ke LSP pilihan Anda itu, bukan ke LSP default.

Yang terkirim ke LSP:

  • alamat IP perangkat Anda (terlihat oleh server mana pun yang Anda hubungi lewat internet, sama seperti situs web mana pun);
  • identitas node Lightning Anda (kunci publik node) dan data yang diperlukan untuk membuka channel dan merutekan pembayaran, termasuk invoice yang Anda bayar atau terima dan jumlahnya;
  • token akses layanan LSP, bila operator LSP mensyaratkannya.

LSP memerlukan data ini untuk membuka channel untuk Anda (termasuk channel instan/JIT), meneruskan pembayaran, dan mengembalikan informasi channel kepada Anda. LSP tidak menerima frasa atau seed Anda, dan tidak bisa mengambil dana dari channel Anda hanya karena ia merutekan pembayaran.

b. Server Electrum (data blockchain)

ELNUX memakai server Electrum untuk membaca data blockchain Nusacoin (misalnya header blok dan informasi transaksi yang berkaitan dengan dompet Anda), karena dompet di HP tidak mengunduh seluruh blockchain.

Server Electrum dapat melihat alamat IP Anda dan permintaan data blockchain yang dikirim dompet Anda. Server ini tidak menerima frasa atau seed Anda.

Server default saat ini adalah server Electrum yang dioperasikan bersama LSP di atas. Bila Anda memakai profil LSP lain di masa depan, server Electrum yang dipakai adalah server yang termasuk dalam profil tersebut.

5. Izin perangkat yang dipakai aplikasi

ELNUX hanya meminta izin berikut, dan masing-masing dipakai hanya untuk fungsinya:

  • Internet. Untuk terhubung ke LSP dan server Electrum. Tanpa ini dompet tidak bisa mengirim atau menerima.
  • Kamera. Hanya saat Anda menekan tombol Scan QR, untuk membaca QR invoice. Gambar kamera diproses di perangkat dan tidak dikirim ke mana pun.
  • Getar. Untuk memberi getaran saat pembayaran diterima dan saat konfirmasi pembayaran. Tidak ada data yang dikirim.

Selain itu, ELNUX memakai clipboard hanya saat Anda sendiri menekan tombol Tempel atau Salin: menempel invoice yang Anda salin, atau menyalin invoice/frasa yang Anda minta. Aplikasi tidak membaca clipboard di latar belakang dan tidak mengirim isi clipboard ke server.

ELNUX tidak meminta akses lokasi, mikrofon, kontak, foto, atau berkas di luar area penyimpanan aplikasinya sendiri.

6. Pihak ketiga

Selain LSP dan server Electrum di bagian 4, ELNUX tidak mengirim data ke pihak ketiga mana pun. Tidak ada:

  • layanan analitik;
  • jaringan iklan;
  • pelacak lintas aplikasi;
  • layanan yang membeli atau memperjualbelikan data pengguna.

Bila Anda memakai LSP atau server Electrum pihak ketiga di masa depan, kebijakan privasi operator tersebut berlaku untuk data yang Anda kirim ke server mereka. Kami menganjurkan Anda hanya memakai operator yang Anda percayai.

7. Keamanan dan tanggung jawab Anda

Kami merancang ELNUX supaya kunci Anda tidak pernah meninggalkan perangkat. Namun keamanan dana Anda juga bergantung pada Anda:

  • Cadangkan frasa 12 kata di tempat yang aman dan luring (misalnya ditulis di kertas dan disimpan di tempat aman). Jangan pernah mengirim frasa kepada siapa pun, termasuk kepada kami atau kepada siapa pun yang mengaku sebagai dukungan teknis. Siapa pun yang memegang frasa Anda bisa mengambil dana Anda.
  • Jaga perangkat Anda. Perangkat yang sudah di-root, sudah di-jailbreak, atau dipakai bersama orang lain lebih mudah disusupi. Kunci di perangkat yang sudah disusupi tidak lagi aman, apa pun yang dilakukan aplikasi.
  • Kehilangan frasa berarti kehilangan dana. Tidak ada tombol "lupa frasa", tidak ada pemulihan lewat email, dan tidak ada cadangan di server kami.
  • Periksa sebelum membayar. Pembayaran Lightning bersifat instan dan tidak bisa dibatalkan. ELNUX menampilkan dialog konfirmasi sebelum membayar, tetapi nominal dan tujuan tetap tanggung jawab Anda untuk diperiksa.

Saat ini frasa dan seed disimpan di area penyimpanan pribadi aplikasi di perangkat Anda. Pemindahan penyimpanan kunci ke penyimpanan aman sistem operasi (Keychain di iOS / Keystore di Android) direncanakan sebagai pengerasan lanjutan; sampai pengerasan itu selesai, pernyataan di atas — bahwa kunci hanya ada di perangkat dan tidak pernah dikirim — tetap berlaku, tetapi Anda tidak boleh menganggap kunci itu terenkripsi oleh perangkat keras.

8. Penyimpanan dan penghapusan data

  • Data lokal di perangkat Anda tersimpan selama aplikasi terpasang dan dompet masih ada.
  • Fitur Restore Phrase menghapus dompet yang sedang aktif secara permanen beserta seluruh datanya sebelum memulihkan dompet dari frasa baru. Penghapusan ini tidak bisa dibatalkan.
  • Menghapus aplikasi (uninstall) umumnya menghapus seluruh data lokal ELNUX dari perangkat Anda, termasuk seed dan frasa yang tersimpan di aplikasi. Cadangkan frasa sebelum menghapus aplikasi.
  • Karena kami tidak menyimpan data pribadi Anda di server, tidak ada "akun" yang bisa kami hapuskan atas nama Anda. Untuk menghapus jejak lokal, hapus aplikasi dari perangkat Anda setelah mencadangkan frasa. Log koneksi server (misalnya alamat IP dan waktu koneksi), bila ada, adalah log operasional server LSP/Electrum dan hanya dipakai untuk menjalankan dan mengamankan server, bukan untuk iklan atau pembuatan profil pengguna.

9. Anak-anak

ELNUX ditujukan untuk pengguna dewasa yang secara sah dapat memegang aset kripto di yurisdiksinya. Kami tidak secara sadar mengumpulkan data pribadi dari anak di bawah 13 tahun, karena kami memang tidak mengumpulkan data pribadi dari siapa pun (bagian 2). Orang tua atau wali yang mengetahui anak di bawah umur memakai ELNUX diminta menghubungi kami lewat kontak di atas.

10. Perubahan kebijakan ini

Bila kebijakan ini berubah — misalnya karena ELNUX menambah operator LSP, menambah fitur, atau mengubah cara data ditangani — kami akan memperbarui tanggal berlaku di atas dan mengumumkannya di tempat kebijakan ini dipublikasikan. Perubahan yang mengurangi perlindungan privasi Anda akan diumumkan sebelum berlaku. Terus memakai ELNUX setelah perubahan berlaku berarti Anda menerima kebijakan yang diperbarui.

11. Kontak dan hak Anda

Karena ELNUX tidak mengumpulkan data pribadi Anda di server, sebagian besar hak privasi Anda dilaksanakan langsung di perangkat Anda: Anda bisa melihat, mencadangkan, dan menghapus data Anda dengan memakai aplikasi dan pengaturan perangkat Anda.
